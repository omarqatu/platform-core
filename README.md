# platform-core

The core of a multi-tenant SaaS platform: tenant isolation enforced by PostgreSQL itself (row-level security, grants
and composite foreign keys), identity and membership, roles and permissions, a second scope axis inside a tenant,
automatic auditing, per-tenant background jobs, and a bilingual (Arabic/English) interface. Business modules —
Subscriptions first — are built on top of it.

.NET 10 · EF Core · PostgreSQL 18 · React + TypeScript.
